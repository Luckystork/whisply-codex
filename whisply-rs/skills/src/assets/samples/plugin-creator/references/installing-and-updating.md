# Installing a Whisply plugin draft

1. Scaffold with `scripts/create_basic_plugin.py`.
2. Validate with `scripts/validate_plugin.py`.
3. Open Settings → Plugins and review the declared capabilities.
4. Install only after that review. Whisply signs and enables the plugin; this skill does not.

Updating a local draft: edit `plugin.json` and bundled skills, then validate again before asking the person to review the new version in Settings.
